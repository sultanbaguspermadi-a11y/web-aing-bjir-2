# Sultan Bagus Permadi — Interactive Portfolio

A hand-crafted interactive portfolio prototype inspired by game-menu interaction principles, rebuilt with an original Arabic editorial identity.

## Run locally
Open `index.html` directly, or serve the folder with any local static server.

## Features
- Boot/loading sequence
- Screen-based navigation (Home / Projects / About)
- Keyboard navigation (Arrow keys, Enter, Escape)
- Two featured projects: Lughoti Vokasi and Arabic Scrabble
- Trilingual interface: Indonesian, English, Arabic
- RTL mode for Arabic
- Arabic typography system using IBM Plex Sans Arabic, Noto Kufi Arabic, Noto Naskh Arabic, and Noto Nastaliq Urdu
- Rich motion with reduced-motion support
- Responsive mobile/tablet layout
- No framework dependency
